## 2. Official framework baseline and safe defaults

- **Selected by requestor:** Laravel + Vue + MySQL.
- **Preferred starter:** Official Laravel 13 Vue Starter Kit (Vue 3, TypeScript, Inertia 3) as a **single Laravel application**. Laravel 13 supports PHP >=8.3; use a supported, compatible PHP minor and pin actual patch/container digest during implementation. Revalidate package versions at start.
- **Source layout:** retain the **starter-generated conventional folders as-is** for WP-020. Do not invent or freeze additional custom `Modules/`, `Domains/`, HR directories or advanced DDD organization. Further file organization must be reviewed alongside implementation.
- **MySQL:** 8.4 LTS candidate for development, isolated disposable Docker data. No real KUTMB or HR production datasets, passwords, tokens, host IPs or infrastructure secrets in a public repository.
- **Browser:** Laravel session auth + Inertia, no separately deployed API/SPA, browser JWT or unreviewed third-party auth package.
- **Security precondition:** the starter kit may include Fortify registration, password reset and MFA flows; inspect actual generated routes/configuration and ensure **public registration and unapproved reset/invite flows are disabled** before treating the app as ready for demonstrations. Never create a default real administrator. No production deployment.
- **Docker:** proposed development isolation; avoid privileged host mounts, hardcoded credentials and binding MySQL to an externally accessible interface. Exact compose/path choices may be made as part of the explicitly authorized WP-020 scope **only after inspecting the repo**.
